## 2. ポータル画面

開くと、ブラウザに保存されたキャッシュで即座に表示し、そのあと最新のサマリーを取得して自動で更新します。

- **ステータスストリップ**：配信中（LIVE）件数、配信予定件数、登録チャンネル総数、最終更新日時を表示します。データ取得に問題があるときは警告も表示されます。
- **ランチャーカード**：「推しスケ！」「推しマド！」へ移動します。

## 3. 推しスケ！

ヘッダーのタブで **配信スケジュール** と **チャンネル一覧** を切り替えます（URL の `#channels` でチャンネル一覧を直接開けます）。画面幅が広いときは、ヘッダーに推しマド！への「⊞ 推しマド！」ボタンが表示されます。

### 3-1. 配信スケジュール

`配信監視一覧` シートの監視チャンネルの配信と、ブックマークレットで手動追加した枠（ゲスト出演・メン限など）を表示します。

**並び替え**

| 並び | 内容 |
| :--- | :--- |
| 開始時間順 | 最上部に「現在配信中（LIVE）」を固定表示し、以降を日付ごとにまとめます（「今日」「明日」のバッジ付き） |
| チャンネル別 | `配信監視一覧` シートの記載順（上から順）に、チャンネル単位でまとめます |

**カードの表示**

| 表示 | 意味 |
| :--- | :--- |
| `LIVE`（赤枠） | 現在配信中 |
| `配信予定`（青文字） | 通常の配信予定 |
| `メン限`（緑枠） | メンバー限定配信。開始予定時刻を過ぎても開始が確認できない場合は `メン限・開始済？` になります |
| `まもなく配信開始`（アンバー枠） | 開始まで30分以内 |
| `New` | 新しく検知された枠の目印。表示は**更新回数**で数えます（下記） |

`New` バッジは、閲覧回数ではなく、バックエンドが更新を行った回数（最初の4回まで）で表示されます。更新が15分おきなら、検知から約1時間表示されます。

### 3-2. チャンネル一覧

`チャンネルディレクトリ` に登録したチャンネルを閲覧します。配信中のチャンネルには `LIVE` バッジと赤枠が付きます。

| 並び | 内容 |
| :--- | :--- |
| タグ別 | メインタグごとにセクション分けします。複数のメインタグを持つチャンネルは、`タグマスタ` で先に定義されたメインタグの1か所にだけ表示されます |
| 登録者数順 | 登録者数の多い順 |
| 動画更新日順 | 最新動画の投稿日が新しい順 |

右上の検索ボックスで、チャンネル名またはタグ名による絞り込みができます（入力に合わせて即座に反映されます）。

### 3-3. 絞り込み（2階層タグ）

ツールバーの「絞り込み ▼」で、フローティングのパネルが開きます。`Esc` キーまたはパネルの外側のクリックで閉じます。選択中のチップをもう一度押すと解除されます。

- **メインタグ**（紫）：グループ・箱・大分類など
- **サブタグ**（水色）：属性・企画・ジャンルなど。メインタグを選ぶと、そのメインタグに紐づく配信・チャンネルに存在するサブタグだけが表示されます
- 並び順は、スプレッドシート（`タグマスタ` / `配信監視一覧` / `チャンネルディレクトリ`）の記載順がそのまま反映されます

**タグの折りたたみ**

`タグマスタ` の「表示設定」列で、タグごとに表示方法を指定できます。**この設定が、自動判定より優先されます。**

| 表示設定 | 動作 |
| :--- | :--- |
| 空欄（または `auto`） | 自動判定。該当する件数が **4件未満** のタグは「さらに表示 (+N)」に折りたたまれます |
| `fold`（折りたたみ） | 件数に関わらず、常に折りたたまれます（選択中のタグは展開表示） |
| `always`（常時） | 件数に関わらず、常に表示されます |

次の場合は、設定に関わらず、すべて表示されます。

- **配信スケジュール画面**：メインタグ・サブタグとも、最初から全件表示
- **チャンネル一覧で、メインタグを選択した状態**：絞り込まれたサブタグを全件表示（折りたたみが働くのは、メインタグ未選択のときだけ）

### 3-4. 自動更新と警告バッジ

- **自動更新**：画面を開いている間、3分ごとに最新データへ更新します。別のタブから戻ったときも、前回の更新から3分以上たっていれば更新します。
- **再読込ボタン**：手動更新です。連打を防ぐため、押したあと5秒間は押せません。
- **警告バッジ**（ヘッダー右上）：次の場合に表示されます。
  - 通信に失敗した
  - バックエンドで YouTube API の取得エラーが起きている
  - データが30分以上更新されていない（鮮度低下）
  - 定期更新が45分以上動いていない疑いがある

## 4. 推しマド！

複数の YouTube 配信を1画面に並べて同時視聴するプレイヤーです（PC の横長画面を推奨します）。最大6窓まで使えます。

### 4-1. レイアウト

ヘッダーのボタンで、5種類を切り替えます。動画のプレイヤーを作り直さずに配置だけを変えるため、切り替えても再生が途切れません。

| レイアウト | 窓数 | 内容 |
| :--- | :--- | :--- |
| `1×2` | 2 | 左右2窓 |
| `2窓+チャット` | 2 | 上段に2窓、下段に2窓分のライブチャットを並べて表示 |
| `2×2` | 4 | 4窓のグリッド |
| `1+3` | 4 | 左に大画面のメイン枠1窓、右にサブ3窓。「メインへ」ボタンで、メインにする枠を切り替えられます（音声もその枠に移ります） |
| `3×2` | 6 | 6窓のグリッド |

セットされた枠の数が、いまのレイアウトの窓数を超えると、収まるレイアウトへ自動で切り替わります。

**窓数の少ないレイアウトへ切り替えたとき**

- 画面外に隠れた枠は、元のミュート状態を覚えたまま、自動で一時停止してミュートされます。
- ソロ音声にしていた枠が隠れた場合は、表示中の枠（メイン枠を優先）へソロ音声が移ります。
- 元のレイアウトに戻すと、再生とミュートの状態が復元されます。

### 4-2. チャット

- **`2窓+チャット`**：下段に、1窓目・2窓目のライブチャットを並べて表示します。
- **その他のレイアウト**：右側のサイドバーに、窓ごとのタブでチャットを表示します（`C` キーで開閉）。`2窓+チャット` では、サイドバーはなく、`C` キーを押すと案内が表示されるだけです。
- チャットが見えない状態（サイドバーを閉じた、非表示の枠など）では、チャットの `iframe` を破棄し、裏での通信を止めます。

### 4-3. 音声操作とショートカット

複数の配信が同時に鳴らないよう、ワンタッチで音声を切り替えられます。

| キー / ボタン | 動作 |
| :--- | :--- |
| `1`〜`6` / 各窓の「🔊 ソロ」 | その窓だけ音声ON（赤枠）にし、ほかをミュート。同じ窓をもう一度押すとソロを解除 |
| `M` / 「🔇 全ミュート」 | すべての窓をミュート |
| `U` / 「🔊 全ミュート解除」 | 表示中のすべての窓のミュートを解除 |
| `C` / 「💬 チャット」 | チャットサイドバーの開閉 |
| `D` / 「📺 推しスケから選ぶ」 | 配信枠の選択ドロワーの開閉 |
| `F` / 「⛶ 没入」 | ヘッダーを隠す没入モードの切り替え |
| `Esc` | ドロワーを閉じる |

- 入力欄にフォーカスがあるとき、および `Ctrl` / `Alt` / `Meta` キーとの同時押しでは、ショートカットは働きません。
- 窓ごとの音量スライダーを0より大きくすると、その窓のミュートが解除されます。
- 最初に配信をセットした窓は音声ON（ソロ）で始まり、2窓目以降はミュートで始まります。
- **共有URL（`?v=...`）から開いたときは、全窓をミュートした状態で始まります。**

### 4-4. 配信枠のセット

**配信枠選択ドロワー（`D` キー）**

- 「推しスケ！」と共有している配信中・配信予定の一覧が表示されます。カードをクリックすると、最初の空き枠にセットされます（セット中のカードにもう一度クリックすると、その枠を解除）。
- 「LIVE のみ」のチップと、メインタグでの絞り込みができます。
- 「最新取得」で、最新の一覧を取得します（連打防止のため、5秒間は押せません）。
- 「全窓クリア」で、すべての枠を空にします。
- **配信中を一括展開**：現在配信中の枠を、最大6件まで自動配置します。既存の枠は、すべてクリアされます。

**URL・動画IDの手動追加**

監視外の配信は、入力欄に URL または動画 ID を入れて追加できます。区切りは、カンマ・スペース・読点・改行が使えます。

| ボタン | 動作 |
| :--- | :--- |
| ＋空き枠へ追加 | 空いている枠に順に追加します。重複は除かれます |
| ⚡入力枠で一括セット | すべての枠を入力した内容で置き換えます |

対応する形式は、11桁の動画 ID、`watch?v=`、`youtu.be/`、`/live/`、`/shorts/`、`/embed/` です。チャンネル名とタイトルは、スケジュールのデータにあればそれを使い、なければ再生開始時にプレイヤーから取得します。

**URL による状態の保存**

セットしている動画 ID（途中の空き枠は `-`）、レイアウト、メイン枠の番号が、ブラウザの URL に自動で反映されます。

```
?v=ID1,-,ID3&layout=2x2&main=2
```

この URL をブックマークまたはコピーすれば、同じ窓構成をいつでも復元できます。

**自動更新**

3分ごとに、バックグラウンドで最新のスケジュールへ更新します（タブが非表示の間は止まり、戻ったときに更新します）。

### 4-5. Chrome 拡張機能との連携

拡張機能（`oshimado-ss`）を導入している環境では、各窓の上部バーの📷・👍が拡張機能と連携して動きます。

**📷 原寸スクリーンショット**

- 枠線や画面の UI が映り込まない、動画そのものの画像を PNG で保存します。
- 解像度は、**その時点で再生されている映像の実際の解像度**です（画質の自動調整や設定によって変わります）。高画質で保存したいときは、プレイヤーの画質を上げてから撮影してください。
- ファイル名は `推しマド_#枠番号_チャンネル名_日時.png` の形式です（長いときは、チャンネル名の部分が短くなります）。
- 動画の準備が整っていないときや、保護された動画では、保存できずにエラーが表示されます。

**👍 高評価用ミニウィンドウ**

埋め込みプレイヤーには高評価ボタンがないため、YouTube 本家の視聴ページを小さなウィンドウ（幅 640 × 高さ 780・画面右下）で開きます。

- すでにミニウィンドウが開いていれば、新しい窓を増やさず、同じ窓の URL を切り替えて最前面に出します。
- ミニウィンドウの中では、ライブチャット欄が自動で閉じます。
- ミニウィンドウを開いた直後の自動再生は一時停止されます（最大6秒間）。ウィンドウ内のプレイヤーをクリックするか、`Space` / `K` キーを押すと、通常どおり再生できます。
- この自動制御は、ミニウィンドウの中だけで働きます。通常の YouTube タブには影響しません。
- 拡張機能を入れていない環境でも、ミニウィンドウは開きます（同じ名前の窓を再利用します）。ポップアップがブロックされたときは、新しいタブで開きます。この場合、チャットの折りたたみと自動再生の一時停止は働きません。

**待機画面の表示補正**

配信開始前の待機画面で、サムネイルが見切れないように 16:9 の全体表示にそろえます。また、狭い窓でも「通知を受け取る」ボタンが崩れないよう、コンパクトに整えます。

## 5. ブックマークレット

YouTube のページでブックマークレットを実行すると、確認画面が表示されます。内容を確かめて「登録する」を押すと、登録されます。`Esc` キーまたは画面外のクリックで閉じます。

### 5-1. 動画・配信ページで実行（枠の追加）

対応する URL は、`/watch?v=...` と `/live/...` です。`/shorts/` には対応していません。

確認画面では、「枠種」を選びます（初期値は一般枠なので、登録前に確認してください）。

| 枠種 | 用途 |
| :--- | :--- |
| 一般枠 | 他チャンネルでのゲスト出演（コラボ）枠など、監視一覧にない配信をスケジュールに追加 |
| メン限枠 | API の自動収集で拾えないメンバー限定配信を追加。定期更新による上書き・削除から保護されます（上限200件） |

**上書きのルール**

- **一般枠 → メン限枠**：すでに一般枠として自動取得されている配信を、メン限枠として登録し直すと、メン限枠に上書きされます。
- **メン限枠 → 一般枠**：誤操作を防ぐため、上書きできません。一般枠に戻したいときは、スプレッドシートの `メン限手動枠` シートから、該当の行を削除してください。

終了した配信を登録しようとした場合は、スケジュールからも取り除かれます。

### 5-2. チャンネルページで実行（チャンネルの追加・タグ編集）

対応する URL は、`/@ハンドル名` と `/channel/UC...` です。

1. 確認画面に、既存のタグがメインとサブに分かれて表示されます。チップを押して選択するか、入力欄に新しいタグをカンマ（または読点）区切りで入力します。
2. すでにディレクトリに登録済みのチャンネルでは、現在のタグが自動で入力されます（タグを書き換えて再登録すると、上書き更新になります）。
3. 「登録する」を押すと、チャンネルの名前・アイコン・登録者数などが YouTube API から自動で取得され、`チャンネルディレクトリ` に追加または更新されます。

登録したチャンネルは、手動更新（再読込）または次回の定期更新で、推しスケ！に反映されます。登録先は `チャンネルディレクトリ` のみで、`配信監視一覧`（常時監視の対象）には追加されません。

### 5-3. 注意

- 実行前に、TOKEN の設定が必要です。未設定のときは、案内が表示されて中断します。
- 動画ページが YouTube の画面遷移で開かれた直後は、動画の情報が正しく取れないことがあります。確認画面のタイトルやチャンネルが「不明」と表示されたら、ページを再読み込みしてからもう一度実行してください。

## 6. データの更新・削除ルール

バックエンドの定期更新は15分おきに動き、YouTube API のクォータを節約しながらデータを最新に保ちます。

### 6-1. 取得の範囲

- **取得期間**：いまから **14日後まで** に開始予定の枠だけを取得します。それより先の枠は、14日前になった時点でスケジュールに載ります。
- **1チャンネルあたり**：アップロード一覧の最新10件を確認します。

### 6-2. 自動削除のタイミング

削除された枠や API の一時的な取得漏れで、枠がすぐ消えないよう、**未検出カウント**で猶予を持たせています。

| 状況 | 扱い |
| :--- | :--- |
| 更新で見つからなかった | 連続して見つからなかった回数を数えます。**3回目までは保持し、4回目で削除**します（15分おきなら、約1時間後） |
| 配信中の枠 | 開始から最大12時間は保持します |
| メン限などで、状態を取得できない枠 | 開始予定時刻から5時間たつと、自動で削除されます |
| API の取得に失敗した | 前回のデータを保持し、削除しません |

### 6-3. 登録できる数の上限

| 対象 | 上限 |
| :--- | :--- |
| チャンネルディレクトリ | 500件 |
| メン限手動枠 | 200件 |

## 7. トラブルシューティング

| 症状 | 確認すること |
| :--- | :--- |
| データが古い、警告バッジが出ている | 通信状態を確認し、再読込を押してください。30分以上更新されていない場合は、バックエンドの定期トリガーが動いているか、Apps Script の「実行数」で確認してください |
| 登録したチャンネルが一覧に出ない | 再読込するか、次の更新を待ってください。チャンネル一覧タブを開き直すと、全件を再取得します |
| 推しマド！で📷・👍が拡張機能として反応しない | `chrome://extensions` で拡張機能が有効か、推しマド！のタブを再読み込みしたかを確認してください。自分の GitHub Pages の URL に書き換えていない場合も動きません（[README.md](./README.md) の 6-6 を参照） |
| 👍で別タブが開く | 拡張機能が未導入または未検出か、ポップアップがブロックされています。ブラウザのポップアップ許可を確認してください |
| スクリーンショットの解像度が低い | その時点で再生されている画質で保存されます。プレイヤーの画質を上げてから撮影してください |
| 待機画面の表示補正やチャットの自動折りたたみが効かない | YouTube 側の画面構造が変わった可能性があります。拡張機能の対応待ちになります |
| 共有URLで開いたら、音が出ない | 仕様です。複数の窓から同時に音が出ないよう、全窓ミュートで始まります。`1`〜`6` のキーでソロにするか、`U` キーでミュートを解除してください |
| ブックマークレットで「TOKEN を設定してください」と出る | `ブックマークレット.txt` の `TOKEN` を設定してください |
| ブックマークレットで「配信ページ、またはチャンネルページで実行してください」と出る | 動画（`/watch`・`/live`）か、チャンネル（`/@...`・`/channel/...`）のページで実行してください |
