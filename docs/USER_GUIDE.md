# 推しスケ！＆推しマド！ ユーザーガイド（機能・操作リファレンス）

**「推しスケ！」「推しマド！」の画面構成・操作方法・ショートカット・データ更新ルールをまとめた自分用リファレンスです。**

---

## 1. アプリ全体の構成（3画面＋補助ツール）

| 画面 / ツール | ファイル名 | 主な役割 |
| :--- | :--- | :--- |
| **ポータル画面** | `index.html` | 全体の入口。配信中・予定件数のサマリー確認と各画面へのランチャー |
| **推しスケ！** | `oshisuke.html` | 配信スケジュール一覧＆登録チャンネル一覧の閲覧・絞り込み・検索 |
| **推しマド！** | `oshimado.html` | 最大6窓の同時視聴プレイヤー・チャット表示・原寸スクショ・高評価連携 |
| **登録補助** | ブックマークレット | YouTubeの動画・チャンネルページから手動で枠やチャンネルを追加・上書き |
| **拡張機能（任意）** | `oshimado-ss` | 複窓からの原寸スクショ撮影・高評価ミニウィンドウ再利用・待機画面UI補正 |

---

## 2. ポータル画面（`index.html`）

アクセス時にローカルキャッシュから0秒で初期表示を行い、裏側で最新サマリーを取得して自動反映します。

* **上部ステータスストリップ**
  * **LIVE（配信中）件数**・**配信予定件数**・**登録チャンネル総数**・**最終更新日時**をひと目で確認できます。
  * API取得エラーが発生している場合は警告表示が出ます。
* **ランチャーカード**
  * 「推しスケ！」「推しマド！」それぞれの画面へワンクリックで移動できます。

---

## 3. 推しスケ！（`oshisuke.html`）

ヘッダー左上のタブで **「配信スケジュール」** と **「チャンネル一覧」** を切り替えられます（URLの `#channels` でも直接開けます）。

### 3-1. 配信スケジュールビュー

厳選した常時監視チャンネルの配信予定と、ブックマークレットで手動追加した枠（ゲスト出演・メン限など）を表示します。

* **並び替え（ソート）**
  * **開始時間順**：最上部に「現在配信中（LIVE）」を赤枠セクションで固定表示し、以降の配信予定を日付ごと（「今日」「明日」バッジ付き）に整理します。
  * **チャンネル別**：`配信監視一覧` シートに記載されている順（上から順）にチャンネル単位で配信枠をまとめます。
* **カードのバッジ・強調表示**
  * `LIVE`（赤枠）：現在配信中の枠
  * `配信予定`（青文字）：通常の配信予定枠
  * `メン限`（緑枠）：メンバー限定配信枠（開始予定時刻を過ぎても未開始・判別不能な場合は `メン限・開始済？` 表示に変化）
  * **まもなく配信開始**（アンバー枠）：開始30分前を切った枠を強調表示
  * `New` バッジ：新しく検知されてから一定回数（4回）以内の更新で表示される新着目印

### 3-2. チャンネル一覧ビュー（`#channels`）

気になった配信者や周辺チャンネルをストックした「チャンネルディレクトリ」を閲覧できます。

* **並び替え（ソート）**
  * **タグ別**：メインタグごとにセクション分けして表示します（複数メインタグを持つチャンネルは、`タグマスタ` の上で定義されている最初のメインタグ1箇所にのみ配置され重複しません）。
  * **登録者数順**：チャンネル登録者数の多い順に表示します。
  * **動画更新日順**：最新動画の投稿日が新しい順に表示します。
* **ライブ中ハイライト**：現在配信中のチャンネルにはアイコン下に `LIVE` バッジと赤枠ハイライトが付きます。
* **インクリメンタル検索**：右上の検索ボックスから「チャンネル名」または「タグ名」でリアルタイムに絞り込めます。

### 3-3. 絞り込み（2階層タグ・チャンネル）と表示ルール

ツールバーの **「絞り込み ▼」** ボタンからプルダウン形式でフィルターを開けます（外側クリックまたは `Esc` キーで閉じます）。選択中のチップを再クリックすると解除されます。

* **表示順の基本ルール**
  * 絞り込み欄のタグやチャンネル、およびチャンネル別・タグ別セクションの並び順は、**スプレッドシート（`タグマスタ` / `配信監視一覧` / `チャンネルディレクトリ`）に入力されている順（上から順）** がそのまま反映されます。
* **2階層タグの連動**
  * **メインタグ**（紫）：グループ・箱・大分類など
  * **サブタグ**（水色）：属性・企画・ジャンルなど。メインタグを選択すると、**選択したメインタグに紐づく配信・チャンネルに存在するサブタグのみ**が動的に抽出されます。
* **タグの折りたたみ仕様（`タグマスタ` の表示設定）**
  * `タグマスタ` の表示設定列には以下の3パターンを指定できます。
    * **空白（または `auto`）**：自動判定。表示対象が **3件未満** のタグは自動的に「さらに表示 (+N)」に折りたたまれます。
    * **折りたたみ（`fold`）**：件数に関わらず常に「さらに表示 (+N)」に折りたたまれます（選択中のタグは展開表示）。
    * **常時（`always`）**：件数に関わらず常に表示されます。
  * **例外（全件表示されるケース）**：
    * **配信スケジュール画面**では、表示されるタグ数が限られているため、上記の表示設定に関わらず**メインタグ・サブタグともに最初から全件表示**されます。
    * **チャンネル一覧画面**でも、**メインタグを選択して絞り込んだ状態では、動的に抽出されたサブタグは全件表示**されます（「すべて」表示時のみ折りたたみが有効）。

### 3-4. 自動更新・ヘルスチェック表示

* **自動リフレッシュ**：タブを開いている間、**3分ごと**にバックグラウンドで最新データへ自動更新します（別タブから戻った際も、前回更新から3分以上経過していれば自動更新）。
* **再読込ボタン**：手動更新用。API連打防止のため、押下後5秒間のクールダウンがあります。
* **警告バッジ（ヘッダー右上）**：通信エラー時、GAS側のYouTube API取得エラー時、30分以上データが更新されていない場合（鮮度低下）、45分以上定期バッチが動いていない疑いがある場合に警告バッジが表示されます。

## 4. 推しマド！（`oshimado.html`）

複数のYouTube配信を1画面に並べて同時視聴できる複窓プレイヤーです（PC・横長画面推奨）。

### 4-1. 画面レイアウトとチャット表示

ヘッダーのレイアウト切替ボタンから5種類の配置を切り替えられます。プレイヤーのDOMを破棄せずに配置変更するため、切り替え時に動画の読み込みが途切れません。

* **`1×2`**：左右2窓
* **`2窓+チャット`**：上段に左右2窓、下段に2枠分のライブチャットを並列表示
* **`2×2`**：4窓グリッド
* **`1+3`**：左（またはメイン枠）に大画面1窓＋サブ3窓（計4窓）
* **`3×2`**：最大6窓グリッド

#### 非表示枠のスマート制御
* 4窓や6窓から「2窓」など枠数の少ないレイアウトへ切り替えた場合、画面外に隠れた枠は**元のミュート状態を記憶したまま自動的に一時停止＆ミュート**されます（裏での通信や音声被りを防止）。
* 音声ソロにしていた枠が非表示になった場合は、表示中の枠（メイン枠優先）へ自動的にソロ音声が移ります。元のレイアウトに戻すと再生・ミュート状態も自動復帰します。
* チャット欄は、非表示レイアウトへの切替時やサイドバーを閉じた際に `iframe` を破棄して通信・メモリ消費を停止します。

### 4-2. 音声操作＆キーボードショートカット

複数の配信が同時に鳴らないよう、ワンタッチで音声を切り替えられます。

| 操作 / キー | 動作内容 |
| :--- | :--- |
| **`1` 〜 `6` キー** または各枠の **「🔊 ソロ」** | 指定した枠だけ音声ON（赤枠ハイライト）にし、他の枠をすべてミュート |
| **`M` キー** またはヘッダーの **「🔇 全ミュート」** | 全枠を一括ミュート |
| **`U` キー** またはヘッダーの **「🔊 全ミュート解除」** | 現在画面に表示されている全枠のミュートを一括解除 |
| **`C` キー** | 右側のチャットサイドバーの開閉 |
| **`D` キー** | 「配信枠を選択」ドロワーの開閉 |
| **`F` キー** | ヘッダーを隠す没入モードの切り替え |

※ 共有URL（`?v=...`）から直接開いた場合は、いきなり複数窓から同時に音が出るのを防ぐため、初期状態で全枠ミュートとして起動します。

### 4-3. 配信枠のセット＆URL共有

* **配信枠選択ドロワー（`D` キー）**
  * 「推しスケ！」と共有している配信中・配信予定リストから、空いている枠（または指定した枠）へワンクリックで配信をセットできます。
  * **配信中を一括展開**：現在配信中の枠をまとめて空きスロットへ自動配置します。
  * **URL / 動画ID貼り付け**：監視外のYouTube URLや動画IDを複数行貼り付けて追加できます（再生開始時にチャンネル名・タイトルを自動補完）。
* **URL状態の自動同期**
  * 現在セットしている動画ID（途中の空き枠 `-` も保持）・選択中のレイアウト・メイン枠番号はブラウザのURLパラメータ（例：`?v=ID1,-,ID2&layout=2chat&main=2`）へリアルタイムに反映されます。そのままブックマークやURLコピーをすれば、同じ窓構成をいつでも復元できます。

### 4-4. Chrome拡張機能（`oshimado-ss`）連携機能

ローカルChrome拡張機能を導入している環境では、各枠の上部バーから以下の連携機能が動作します。

* **📷 原寸スクリーンショット撮影**
  * 枠のフレームやUIが一切映り込まない、配信元のネイティブ解像度（`1920×1080` 等）そのままのPNG画像を即時ダウンロード保存します（ファイル名：`推しマド_#枠番号_チャンネル名_日時.png`）。
* **👍 ワンクリック高評価ミニウィンドウ**
  * 埋め込みプレイヤーには高評価ボタンがないため、押すと画面右下にYouTube本家視聴ページのミニウィンドウ（`640×780`）を開きます。
  * すでにミニウィンドウが開いている場合は**新しい窓を増やさず同じ小窓のURLを切り替えて最前面にフォーカス**するため、複数枠の高評価をテンポよく押せます。
  * 小窓内ではライブチャットが自動で折りたたまれ、複窓側との音声被りを防ぐため初期自動再生も自動で一時停止されます（小窓内をクリックするか `Space` / `K` キーで再生可能）。
* **待機画面UIの自動補正**
  * 配信開始前の待機画面サムネイルが見切れないよう16:9全体表示に補正し、狭いサブ枠でも「通知を受け取る」ボタンが崩れないようコンパクトに整えます。

## 5. データ取得・自動削除・手動登録（ブックマークレット）のルール

バックエンド（GAS）の定期バッチは15分おきに稼働し、YouTube Data APIのクォータを節約しながらデータを最新に保っています。

### 5-1. 配信枠の取得期間と自動削除の仕様

* **取得対象期間（14日後まで）**
  * 配信予定枠は、**現在時刻から14日後（2週間先）までに開始予定の枠のみ**を取得対象としています。14日より先の遠い予定枠は、開始14日前に近づいたタイミングで自動的にスケジュールへ載ります。
* **削除・ゲリラ終了した配信の自動削除タイミング**
  * 配信者側で枠が削除された場合や、一時的なAPI取得漏れで即座に消えてしまうのを防ぐため、「未検出カウント（猶予システム）」を採用しています。
  * 定期バッチ（15分おき）で **連続3〜4回（約45分〜1時間）** 見つからなかった枠は「削除または終了済み」と判定され、スケジュールから自動的に削除されます。
  * メンバー限定枠などでYouTube APIから状態が取れなくなった枠についても、開始予定時刻の経過後 **最大5時間** を経過すると自動的にクリーンアップ（削除）されます。

### 5-2. ブックマークレットでの手動追加・上書きルール

YouTubeの画面を開いた状態でブックマークレットを実行すると、監視対象外の枠や新規チャンネルを手動登録できます。

* **YouTube 動画・配信ページで実行した場合（枠の追加・上書き）**
  * **一般枠として登録**：他チャンネルでのゲスト出演（コラボ）枠など、監視一覧にない枠をスケジュールへ追加します。
  * **メン限枠として登録**：APIの自動収集では拾えないメンバー限定配信枠をスケジュールへ追加します（定期バッチの上書きからも保護されます）。
  * **一般枠 → メン限枠への上書き**：すでに一般枠として自動取得・登録されている配信に対して、ブックマークレットから「メン限枠」として登録し直すことで、**メン限枠へ上書き変更**できます。
  * **メン限枠 → 一般枠への上書き不可**：誤操作による保護解除を防ぐため、一度「メン限枠」として登録された枠をブックマークレットの「一般枠」操作で上書きすることはできません（一般枠に戻したい場合は、スプレッドシートの `メン限手動枠` シートから該当行を削除してください）。
* **YouTube チャンネルページで実行した場合（チャンネル一覧への追加・タグ編集）**
  * 既存のタグチップ選択または新規タグ入力を行い、`チャンネルディレクトリ` へ追加・タグ更新ができます（チャンネル一覧表示は次回定期更新または手動更新で反映されます）。
